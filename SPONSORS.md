# Sponsors

drt is open source and free. Sponsorship keeps it maintained: it pays for the
live Snowflake, Databricks and BigQuery accounts every release is tested
against, and for the tools used to maintain and review the project.

**[Sponsor drt-hub on GitHub](https://github.com/sponsors/drt-hub)**

## Thank you

Sponsors who opted in to being named appear here. Nobody is listed without
asking.

## How sponsorship works

- Sponsorship does not unlock features and there is no paid tier of drt-core.
- Tiers are listed on the [sponsor page](https://github.com/sponsors/drt-hub).
  Higher tiers include a name or logo in the README and on the docs site, and
  a `sponsor` label on issues you file (triaged within a week as a goal, not a
  guarantee: this is a small project, not a support contract).
- To be listed, or to be removed, open a pull request editing this file or
  write to the maintainers.
